# 数字人综合情感陪伴对话模型

动感地带 AI+高校创智计划技术赛道项目。当前正式方案为 V5，包含情绪识别、回复生成、用户画像与离线推理入口。

## 当前方案

- 情绪：Qwen2.5-7B-Instruct，NF4量化、LoRA与16类分类头。
- 回复：Qwen2.5-3B-Instruct + reply-v3 LoRA。
- 画像：CPU性格与风格分类器，BERT兴趣分类器。
- 公开推理输入没有记忆库时，memory_refs 输出空数组。

## 恢复部署

**仅克隆此仓库不能运行完整模型。** 权重、分类器资产和离线依赖保存在独立交接包中，不上传普通Git。交接包为部署文件归档，不是Docker镜像。

正式交接包：`V5可直接恢复交接包-20261009.tar`

SHA256：`e072469ef4c984504ad6f4f3e29bf837aedb457f723630bcf17f70bd8d6ed7d2`

在匹配的Linux基础环境中，将交接包解压到 `/root`，恢复 `/root/participant` 及其全部资产。按照包内 `HANDOFF_README.md` 核验文件并运行短验证，再使用统一入口：

```bash
bash /root/participant/start.sh /path/to/input.jsonl /path/to/output_directory
```

运行环境：Python3.12、PyTorch2.10.0+cu128、Transformers4.57.6、Accelerate1.15.0、PEFT0.17.1、bitsandbytes0.48.2。需要可用CUDA显卡；本仓库不包含操作系统、CUDA驱动和完整运行镜像。

正式代码同时保留 `configs/inference_config.json` 和兼容入口；不要只复制模型权重而遗漏配置、分类器与运行依赖。仓库中的 manifest 描述完整部署资产，克隆后的代码目录并不是完整部署包。

## 结果与限制

同一批101条本地样本，原始3B方案到V5的情绪准确率为13.86% → 74.26%，格式问题2条 → 0条；回复BLEU-4为0.004532 → 0.095861，ROUGE-L为0.137794 → 0.227573，BERTScore为0.587340 → 0.658739。

这些是固定条件下的本地诊断，**不是官方分数**。不同报告中的样本集合、提示和计时约定存在差异，应阅读原始报告再比较。平台测试成功由用户反馈，尚无官方成绩。性格与风格识别仍是短板。

历史报告中的服务器路径用于描述当时实验，不代表当前文件仍在该服务器；恢复时以交接包说明为准。
