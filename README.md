# 数字人综合情感陪伴对话模型

提交版本：`submission-20261105`。模型与推理实现冻结于已验收镜像 `migu-submission:20261103`。
## 最终方案

|模块|提交实现|选择依据|
|---|---|---|
|A 情绪识别|Qwen2.5-7B-Instruct，NF4、V5 LoRA、16类分类头|后续同任务候选未达到替换条件|
|B 用户画像|CPU性格分类、冻结B008风格分类、BERT兴趣分类|兼顾F1和完整标签匹配；使用实际交付权重|
|C 回复生成|Qwen2.5-3B-Instruct、reply-v3、FP16|后续候选未形成可靠的综合质量与速度收益|
|推理工程|I0画像CPU计算缓存|101点完整输出与对照一致|

524点开发回归：情绪准确率80.15%；性格、兴趣、风格完整匹配分别62.60%、86.26%、53.24%；回复BERTScore 0.671050。前100点平均延迟5231.69ms，V100S单卡，不计加载。
