## 离线运行

在具备NVIDIA驱动、Docker GPU支持的Linux主机上，使用绝对路径挂载输入和结果目录：

```bash
docker run --rm --network=none --gpus device=0   -v /absolute/input:/input:ro   -v /absolute/results:/results   migu-submission:20261103 /input/input.jsonl /results
```

统一入口是`bash /root/participant/start.sh INPUT_JSONL RESULT_DIR`；镜像ENTRYPOINT已配置。输出`submission.jsonl`和`performance_report.json`。运行环境、模型与依赖均在镜像内，不需要挂载项目、联网下载或额外基础镜像。已在V100S 32GB单卡上验证。

源码Dockerfile使用历史构建基础镜像；Release中的完整导出包已经包含所有依赖层，恢复不需要另行下载该基础镜像。普通源码包不是完整构建上下文。

## 存储空间与历史问题

压缩只减少下载体积，不减少Docker导入后的层占用。恢复时需同时容纳分卷与32.95GB归档，Docker存储还需容纳约32.92GB镜像及导入临时空间。分卷、归档、Docker共用分区时，建议至少预留100GiB；这是工程余量建议，实际还取决于已有共享层与Docker后端。分别检查下载目录和`docker info`显示的Docker根目录。

历史配置路径缺失已修复：镜像同时包含`config.json`和`configs/inference_config.json`。历史Docker导入失败与磁盘空间不足有关，不能用压缩文件大小代替导入空间需求。
