# 第五轮技术方案与复现说明

本轮候选将情绪字段改为独立7B分类器，保留已有3B回复模型、CPU性格/风格模型和BERT兴趣模型。三个分支读取截至当前用户轮次的历史；回复没有使用预测标签或标准答案作为输入，方便分别验证。公开测试没有memory bank，memory_refs固定为空数组。

## 情绪分类

基座为公开Qwen2.5-7B-Instruct，NF4双重量化、BF16计算。分类任务为16类单标签交叉熵；all-linear LoRA rank16、alpha32、dropout0.05，另训练分类头。分类头输入做RMS归一化，推理保留相同钩子。长输入最多2048 token，保留前256和末1792。

原训练集18653个预测点；训练对话内部划分3690点校准数据，14963点训练池。7B第二轮1200步、第三轮从适配器权重续训2600步；累积批量4。权重续训不等于恢复优化器，累计处理样本量不等于完整覆盖所有样本。分类训练不使用开发或留出答案。

先前评估只取每段对话第一个预测点，存在早期轮次偏置。本轮保持同一200段开发对话，扩展为全部524点，选择最终检查点后再比较其余423段开发对话全部1048点。后者仍是开发核查，不称全新独立测试。比较不确定性按对话成组重抽样。

推理调用prepare_model_for_kbit_training使未量化参数保留FP32，计算使用BF16 autocast，与训练精度匹配；不能混用不同精度的历史分类结果。

## 回复和画像

回复继续使用Qwen2.5-3B-Instruct与reply-v3适配器，纯中文文本生成，上限768 token、贪心解码、重复惩罚1.05。其既往训练仅600步，不能称充分收敛。不同版本提示策略一起变化的收益，不能全部归因于微调；本轮补充相同提示、相同解码下的未微调对照。

性格和风格保留CPU分类器，兴趣使用已有33标签BERT的兴趣输出。新BERT风格覆盖在1048点上集合匹配和F1均下降，已撤回。画像集合完全匹配和microF1同时记录，防止空数组命中掩盖有效标签召回低的问题。

## 验证与交付边界

完整入口接收测试JSONL和结果目录，逐条生成全部预测，首100点记录耗时。计时含分类、回复、画像、解析以及逐条CPU推断时间，模型加载排除；CPU分支先执行，其逐样本耗时加到对应GPU流水线耗时。已有结果目录哨兵必须保留，只增加规定输出文件。

同一101点实际运行初始未微调模型、旧V4、3B分类候选和7B分类候选，记录预测文件哈希和性能关联。216点此前留出对话只作回归。断网路径测试拒绝外网连接；它不能替代真正Docker镜像离线测试。

拟交付V5采用实体文件、模型哈希和固定依赖记录，避免依赖开发软链接。V4留作回退。是否正式部署及持久备份位置以本轮deployment.json、package.json为准，不以候选目录名判断。

平台GPU反复出现新进程无法访问设备的故障，根因尚未证实；已记录重启和恢复过程，不更改驱动或设备权限。本轮使用有结束条件的具体验证任务，不设置显卡常驻服务。

官方70分自动评测公开项目为情绪25、回复20、画像15、推理性能10；其余技术评审30。回复融合、画像多标签匹配及延迟换算规则未全部公开。本地报告只给原始指标，没有计算官方总分。还需平台保存镜像和官方测评，尚不能宣称已获奖或已完成正式提交。
