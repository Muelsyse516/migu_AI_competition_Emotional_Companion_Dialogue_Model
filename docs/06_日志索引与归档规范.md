# 日志索引与归档规范

## 本次整理

统一以实验目标、配方、固定预算、对照、评测范围、结果和采用结论记录。无变化的巡检与相近失败配方合并，不保留重复进度叙述。历史指标不改写；未完成、未通过和未采用分别说明。

`02_实验记录与取舍.md`覆盖A/B/C研究，`05_性能实验汇总.md`覆盖最后四类性能尝试，`04_完整评测与质量边界.md`记录提交镜像验收。`history/`保存早期已整理的项目记录，代表当时状态；恢复部署以当前文档为准。

公开日志包包括统一文档、聚合指标、正式文件摘要、原始日志校验索引及发布校验文件。原始训练日志、检查点和对话级诊断保留在内部实验归档；公开索引记录来源和摘要，不包含对话原文、参考答案、凭据或机器专属绝对路径。原始日志不能因未采用而伪装为成功结果。

## 复核方式

1. 通过镜像及分卷SHA256确定发布对象。
2. 通过代码摘要和资产清单核对运行实现与模型。
3. 通过聚合指标和实验索引追溯采用依据。
4. 同数据范围、同指标和同计时口径下比较；禁止跨数据表计算增益。

历史V5训练暴露未完全重建、开发集被反复使用、辅助评审不是独立人工金标准等限制仍保留。文档压缩不改变这些证据边界。
