# 第三轮迭代报告（2026-10-06）

## 本轮目标与数据

补齐之前漏评的回复质量，并把有效组件接入官方统一入口。使用固定dev200：200个开发集独立对话，各取一个预测点，排除旧smoke100出现过的对话。训练和内部阈值校准只使用训练集，不使用dev200答案；开发集用于比较与选择，不能称为全新测试集。

## 回复训练的收益

Qwen2.5-3B-Instruct基座，all-linear LoRA r16、alpha32、dropout0.05，BF16、梯度检查点、batch1/累积4，600步、学习率5e-5。仅学习assistant回复，输入为用户轮次截止的完整历史；prompt部分labels=-100。不用情绪或画像金标辅助推理。训练约17分46秒，loss2.2259，只约0.14轮，不能声称充分收敛。

基座回复使用原官方JSON提示，新模型输出纯文本。比较的是整个回复方案（提示和微调一起变化），不是对LoRA本身收益的严格单变量消融。

新回复非空白字符总数32462，参考30682；旧回复10435，长度惩罚明显。BLEU增益部分来自长度接近参考，不能全部解释为情感陪伴能力提升。ROUGE和BERTScore也提高，为收益提供补充证据。人工检查仍需注意冗长、建议过多、编造前提与用户意愿。

## 未采用的改动

画像v3采用多通道历史特征和逐标签F1阈值，召回提高但误报增加。相同dev200：性格集合完全匹配64.5%→53.5%，风格54%→40%，因此不采用。

画像v4阈值以训练集按对话留出的内部校准集确定，目标0.7集合匹配+0.3microF1；该目标是实验选择约定，非官方公式。性格集合匹配69.5%高于v1的64.5%，但microF1从0.346降至0.325；风格集合匹配52.5%低于54%。暂不全面替换。最终候选继续使用classical-v1性格/风格和structured-v2情绪/兴趣。

解码回归：前50条开发样本加3个已知截断案例，共53条；这组数据是针对性诊断，不是独立测试。原512上限继承基座重复惩罚1.05：BLEU0.11220、ROUGE0.24404，3次触顶；重复惩罚1.08和768上限：BLEU0.10468、ROUGE0.23626，0次触顶。未默认采用1.08。完整流水线候选只把上限改为768，保持原来1.05；与200条表格设置不同，另行回归验证。

回归捕获的实现问题：最初新入口显式使用1.0，而原模型generation_config.json自带1.05。首次完整100条回归出现32条兴趣标签集合差异，虽情绪/性格/风格未变，但兴趣准确率下降。该次报告保留为失败记录，不采用。随后将结构与回复的重复惩罚都显式固定1.05，重新验证；不再依赖模型配置中的隐藏默认值。此前“无重复惩罚”描述不准确，应理解为没有额外覆盖默认参数，现已纠正。
