# 第一轮微调诊断（2026-10-05）

已通过SSH直接执行。未提交官方测评，未覆盖原模型或官方程序。

## 实验条件
同一100条开发样本；同一排序固定的官方提示词；greedy生成；repetition_penalty=1.1；max_new_tokens=1200。分别测试Qwen2.5-3B-Instruct及300步LoRA合并模型。

|平均耗时|2.22秒|4.00秒 |

所有指标均为本地诊断；画像F1及完全匹配不宣称是官方评分公式。未评估官方回复质量指标。100条样本不足以证明泛化提升，保留集尚未用于这轮比较。

## 已核实的问题
- 训练提示词情绪列表排序，原推理提示词使用集合的遍历顺序，跨进程不固定；已在隔离的测试副本中固定排序。
- 原模型和合并模型的100条输入分词结果完全一致，chat模板一致。
- 旧版4条问题中存在生成重复及1200-token上限截断；轻度重复惩罚使这4条输出完整，但完整100条中出现另3条问题，不能认为格式问题彻底修复。
- 新设置下LoRA在87/100条上输出rational，仍有画像预测偏向。
- 空画像会抬高完全匹配指标：标准答案性格、兴趣、风格分别有60%、75%、53%为空。故增加标签级精确率、召回率、F1及答案非空时完全匹配作为补充诊断。
- 2048条训练子集筛选时跳过399条超过2048 token的候选样本；不能把该训练当成覆盖全部训练集。

## 决定
保留原基准，不采用LoRA v1作为提交版本。下一轮优先针对情绪和画像设计结构化预测训练，减少长回复对短标签学习的干扰；回复生成单独保留并评价。先做小规模受控实验，扩大开发集验证后再用保留集确认。
