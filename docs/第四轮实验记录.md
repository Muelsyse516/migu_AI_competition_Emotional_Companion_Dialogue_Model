## 两条路线

1. Profile-v5：从 structured-v2 的 LoRA 参数继续训练，只预测 user_profile。17,619 条符合 3,072 token 上限的训练样本，1,034 条过长样本跳过并记录；均匀抽样，学习率 5e-5，1,200 步。保存中间检查点，避免训练更久却无法回退。
2. Profile-BERT-v1：使用已在服务器上的中文 BERT，训练独立的33标签画像分类器。只读取用户发言，长历史保留开头96及结尾414个内容 token。按训练对话分出20%进行内部校准，按内部校准选择两轮中的模型与阈值；不使用验证标签训练。

两项训练暂时共享显卡以利用空闲计算时间；训练速度不作为推理性能证据。最终耗时比较须在没有其他 GPU 任务运行时进行。

## 验证约束

- 固定 dev200 用于开发比较；它已被使用，不能宣称是独立测试。
- 从剩余未用的80段 holdout 对话各取一个预测点，生成 final80，只在开发选择完成后进行最终确认。不使用它调阈值或选择训练轮次。
- 比较画像集合完全匹配、微平均精确率/召回率/F1以及非空标准答案的识别情况，避免全空预测的虚高指标。
- 本地画像指标和校准目标不是官方公开公式，不计算虚构的官方总分。
- 性能提升必须保持情绪与回复能力、输出格式及离线入口正常；新版本未通过验证前不覆盖已有最好版本。

训练原始标注检查发现：性格非空8,161/18,653，兴趣非空5,735/18,653，风格非空9,922/18,653。标签分布不均衡；部分同一训练对话不同预测点的标签发生变化。这些现象说明需要学习逐轮标注习惯，但不能仅凭它断言官方数据错误。
